# CampusCart 🛒

CampusCart is a full-stack marketplace platform built for college students to buy, sell, and exchange products within their campus community.

## Features

* Buyer & Seller role-based system
* Product listing management
* Seller dashboard
* Wishlist functionality
* Real-time messaging
* Purchase tracking
* Product search and filtering
* User profile management

## Tech Stack

### Frontend

* React.js
* TypeScript
* Tailwind CSS
* React Router
* Axios
* Socket.io Client

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* Socket.io
